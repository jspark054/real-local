확인 포인트

  • 메인의 9개 카드 = maps.json의 9개 맵 그대로
  • 카드 클릭 → 상세로 슬라이드 전환, 커버 톤이 이어짐
  • 상세 지도의 핀 위치는 각 장소의 실제 lat/lng을 맵별 bounding box에 비례 배치
  • 핀 또는 리스트 항목을 클릭하면 서로 하이라이트
  • 하트(저장) · 공유 버튼은 토스트로 동작 피드백
  • 별점을 클릭하고 코멘트를 작성하면 후기가 등록되고 평균 별점이 즉시 갱신됨
  • 맵 상세의 한 줄 설명 = maps_cleaned.csv의 subtitle (더 이상 "N spots · 지역" 임시 텍스트 아님)
  • 메인 카드 커버의 브라운 뱃지 = maps_cleaned.csv의 city
  • google_maps_link는 데이터에 남아있지만 화면 어디에도 출력하지 않음
